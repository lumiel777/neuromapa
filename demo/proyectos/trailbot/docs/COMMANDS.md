# Commands

| Command | Answer |
|---|---|
| `/today` | The best three hikes for today, with the reason for each |
| `/near` | Every trail within 40 km of your home area |
| `/rate <trail> <1-5>` | Saves your rating; once per trail per day |
| `/stop` | Deletes everything the bot knows about you |
| `/help` | This list |

Anything else gets the help text. The first message asks for a home area (a city name) and a fitness level from one
to five. Both can be changed by sending them again.

The wording is friendly and short: users read it on a trailhead with one bar of signal.
