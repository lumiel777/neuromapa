# Contributing trails

Only trails that someone in the project has walked go into the seed.

1. Add a row to `data/trails.csv` with a new, lowercase slug.
2. Use the coordinates of the trailhead, not the summit.
3. Difficulty: easy is under 6 km without scrambling; hard is anything with exposed ridges or over 18 km.
4. Open a pull request with one trail and a photo or GPX of the walk.

Ratings from users never change the difficulty automatically: Alex reviews them once a month.
