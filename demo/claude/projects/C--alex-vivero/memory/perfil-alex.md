Alex es programador freelance en Rosario. Hace el sistema del Vivero Las Glicinas (ver [[cliente-glicinas]]) y, de
costado, un bot de senderismo en inglés (trailbot), que tiene su propia memoria.

- Prefiere explicaciones cortas, con el archivo y la línea. Si hay que elegir, una pregunta con opciones y una
  recomendación.
- Sabe C# y SQL. No le gusta el JavaScript de más: el panel de Marta es HTML con poco script, a propósito.
- Aprueba antes de cualquier cambio que toque la base de producción o el riego (se puede ahogar un invernadero).
- Trabaja de tarde; a la mañana está en el vivero con Marta, así que a veces prueba desde el celular.
